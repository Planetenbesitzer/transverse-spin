# Transverse Spin Calculations

This repository contains notes on spinor helicity amplitude and transverse spin calculations.

## Contents

- `transverse_spin.tex` - LaTeX document with the main content (English version)
- `transverse_spin.md` - Original markdown notes (Chinese version)

## Building the LaTeX Document

To compile the PDF:

```bash
pdflatex transverse_spin.tex
```

Or using XeLaTeX:

```bash
xelatex transverse_spin.tex
```

## References

Key references for this work:

- Zhite Yu PhD thesis (2308.13080) - Sections 8.1, 2.4, 2.6, 2.7
- Barone-Drago-Ratcliffe review (hep-ph/0104283) - Sections 2, 3, 4, 6
- Peskin & Schroeder - Sections 3.2-3.3, 5.2, Appendix A.2

## Topics Covered

1. **Spinor Convention** - Discussion of helicity basis in spinor eigenfunctions and spin basis decomposition
2. **Factorization Proofs** - Factorization theorems with and without polarization effects

## Author's Notes

This note is primarily for organizing reference materials. Complete mathematical details will be added in future versions.

For complete understanding, it is recommended to combine these materials with field theory textbooks and resources like Weinberg's discussion of particle representations.
